# 光鸭闪推 ⚡

> 嗅探网页中的磁力 / ed2k / 迅雷链接，一键推送到 [光鸭云盘](https://www.guangyapan.com/) 离线下载（云添加）。

## 功能一览

- 🔍 **智能嗅探**：自动识别页面中的磁力（参数顺序任意）、ed2k、迅雷链接（自动解码），支持超链接、正文纯文本、输入框、`data-*` 属性、Shadow DOM 与 iframe
- ⚡ **一键推送**：每个链接旁出现「⚡推送」按钮，点击即推；推送前解析显示资源名称 / 大小 / 文件数
- 📦 **批量推送**：页面右下角面板显示「发现 N 个链接」，支持全部推送；弹窗内也可批量操作
- 🖱 **右键直达**：链接或选中文本上右键 →「推送到光鸭云盘 ⚡」
- 📁 **保存目录**：弹窗内可逐级浏览云盘目录并指定保存位置
- 🔄 **登录同步**：网页版登录一次即可，token 自动同步、到期前自动续期（并回写网页版，两边登录态互不影响）
- 🔔 **状态反馈**：推送结果系统通知 + 徽标提示，弹窗内可查看最近云下载任务

## 安装

1. 下载并解压本文件夹（若以 zip 分发）
2. 打开 Chrome / Edge，访问 `chrome://extensions/`
3. 右上角打开「开发者模式」
4. 点击「加载已解密的扩展程序」，选择本文件夹

## 使用

1. 安装后打开 [光鸭云盘网页版](https://www.guangyapan.com/) 并登录，插件自动同步登录状态
2. 打开任意含磁力链接的页面（已打开的页面需按 F5 刷新一次），链接旁即出现「⚡推送」按钮
3. token 长时间未使用过期时，重新打开一次网页版即可重新同步

## 设置说明

右键插件图标 → 选项：

| 设置 | 说明 |
| --- | --- |
| 推送前确认 | 解析并显示名称/大小/文件数，需点击确认 |
| 推送成功通知 | 系统通知提醒 |
| 自动续期登录 | token 到期前自动续期并回写网页版 |
| 嗅探类型 | 磁力 / ed2k / 迅雷 / HTTP 直链开关（HTTP 默认关闭） |
| 纯文本嗅探 | 识别未做成超链接的正文磁力 |
| 右下角面板 | 「发现 N 个链接」悬浮面板开关 |
| 站点黑名单 | 每行一个 host，支持 `*` 通配，如 `*.example.com` |
| 开发者诊断 | 面板底部折叠区，记录嗅探与凭证同步内部状态（不含 token 内容） |

## 隐私声明

- 凭证与设置仅保存在浏览器本地 `chrome.storage.local`，不上传任何服务器
- 链接嗅探完全在浏览器本地完成
- 网络请求只发往 `*.guangyapan.com`（光鸭云盘官方域名）

## 实现原理（简述）

- 云下载走光鸭云盘官方接口：`resolve_res`（解析）→ `create_task`（创建任务）→ `list_task`（任务列表），目录列表走 `get_file_list`（文件夹以 `resType === 2` 标识）
- 登录凭证：读取网页版存于 localStorage 的 `credentials_<clientId>`（`@xbase/sdk`），续期走 `account.guangyapan.com/v1/auth/token` 并双向同步
- 全部 UI 使用 Shadow DOM 隔离，不依赖 `customElements`（部分环境不可用），不污染页面样式

## 开发注意（重要）

- **修改代码后必须到 `chrome://extensions` 点击本扩展卡片上的「重新加载」按钮**。Chrome 会缓存开发模式扩展的 Service Worker，重启浏览器不会加载新代码。
- 目录结构：`manifest.json` / `src/background`（后台）/ `src/content`（嗅探与凭证同步）/ `src/popup` / `src/options` / `tools`（图标与安装脚本，非运行时依赖）
